## التحكم
- الجوال: أزرار الشاشة (يمين، يسار، بنزين، فرامل، هاند).
- الكمبيوتر: الأسهم أو WASD، والمسافة للهاند بريك.
- أزرار جانبية: إعادة السيارة، قلب اتجاه السيارة (لو المقدمة معكوسة)، تغيير الكاميرا.

## ما تغيّر في المرحلة 2
- إصلاح `importmap` (سبب التوقف عند شاشة التحميل).
- مقياس موحد للسيارة والطريق (0.0325 → السيارة ≈ 5.3 م، الطريق ≈ 320 م).
- السيارة تبدأ على الطريق وتتبع سطحه (ارتفاع + ميل أمامي وجانبي) عبر شبكة ارتفاعات تُبنى من مجسم الطريق.
- مركز دوران السيارة عند منتصف المحورين، وحذف خطوط التحديد غير المرئية من المجسم.
- ظل بسيط تحت السيارة بدل ظلال حقيقية (أخف على الجوال).
- كاميرا تتبع بتأخر بسيط وتبقى فوق الأرض.
- الطريق يتكرر: عند النهاية تعود السيارة للبداية بنفس السرعة.
- لو خرجت السيارة عن الطريق بعيداً تعود تلقائياً.
- شاشة التحميل تعرض سبب الخطأ إن حصل.
